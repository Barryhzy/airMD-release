# Contributing / 参与贡献

欢迎提交 Issue 和 Pull Request。请先阅读中英文 README 中的运行与测试说明。
Issues and pull requests are welcome. Start with the setup and test instructions in the README.

## 报告问题 / Reporting an issue

请提供应用版本、操作系统、复现步骤、预期和实际结果，以及方便公开的最小示例。请勿上传私人笔记、访问令牌或个人资料。
Include the app version, operating system, steps to reproduce, expected and actual behavior, and a minimal example that is safe to share. Do not attach private notes, access tokens, or personal data.

## 修改代码 / Making changes

- 保持改动聚焦，说明修改目的与验证方式。 / Keep changes focused and explain what changed and how it was verified.
- 涉及保存、编码或编辑器内容转换时，补充回归测试。 / Add regression coverage for changes to saving, encoding, or editor content conversion.
- 不要提交依赖目录、工具链、构建产物、测试输出或密钥。 / Keep dependencies, toolchains, build output, test output, and keys out of commits.
- 界面文案修改需同步检查中英文。 / Check both interface languages when changing UI text.
