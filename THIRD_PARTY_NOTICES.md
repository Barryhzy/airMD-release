# Third-party notices

The airMD source is licensed under [MIT](LICENSE). Dependencies retain their own licenses.

[THIRD_PARTY_LICENSES.txt](THIRD_PARTY_LICENSES.txt) contains the license texts and declared license metadata collected for this release from the frontend dependency tree and the locked Rust dependency metadata. The same file is bundled in the macOS application's Resources directory alongside the airMD license. Some packages declare a license in their manifest without shipping a standalone text; those entries are marked in the inventory.

Frontend dependencies are locked in `package-lock.json`; Rust dependencies are locked in `src-tauri/Cargo.lock`.

README badges were generated with Shields.io. Project names and logos belong to their respective projects.
