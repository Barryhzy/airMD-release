# Changelog

## 0.4.3 — 2026-10-27

- Local Markdown editing with visual and source modes.
- Autosave, project folders, document tabs, and heading outlines.
- Simplified Chinese and English interfaces.
- A persistent option to suppress HTML/frontmatter integrity warnings.
- Bilingual READMEs with local badge and screenshot assets.
- macOS Apple Silicon build with personal build paths remapped.
- Project and third-party license notices bundled with the Mac app.

See [release notes](RELEASE_NOTES.md) for installation details and [known limitations](docs/KNOWN_LIMITATIONS.md) for unsupported features. The Windows installer is not included in this release.
