安装说明

  • Windows：运行 airMD_0.4.3_x64-setup.exe，按提示完成安装。安装程序内置 WebView2 引导，无需额外安装运行时。
  • macOS：打开 DMG，把 airMD 拖进「应用程序」。Intel 芯片的 Mac 暂不提供安装包。
macOS 版本使用 ad-hoc 本地签名（无 Developer ID / 公证），首次打开若被 Gatekeeper 拦截：在「系统设置 → 隐私与安全性」里点「仍要打开」，或在应用上右键 → 打开。
