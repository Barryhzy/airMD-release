# airMD · 使用说明

这是一个可以直接编辑的本地 Markdown 文件。左边出现 **+** 和 **⠿** 时，
说明你正悬停在某个段落上——点 **⠿** 可以转换段落类型，点 **+** 可以在下方插入新块。

## 基础格式

支持 **加粗**、*斜体*、~~删除线~~、`行内代码`，以及[链接](https://commonmark.org)。

> 引用块用来强调一段话。
> 它可以是多行的。

## 列表

- 无序列表项
- 第二项
  - 嵌套一层
- 第三项

1. 有序列表
2. 第二步
3. 第三步

- [x] 已经完成的待办
- [ ] 还没做的待办
- [ ] 再列一条

### 标题层级

#### 四级标题

四级标题用来切分小节，字号比正文大、字重更重。

##### 五级标题

五级标题再小一档，仍然明显区别于加粗正文。

###### 六级标题

六级标题用灰色和字距做最后的区分。

## 代码块

```ts
export function greet(name: string): string {
  return `你好，${name}`;
}
```
